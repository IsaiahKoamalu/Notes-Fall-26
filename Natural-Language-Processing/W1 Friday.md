## Context Free Grammar
- a formal system for modeling constituency structure.
- AKA Phrase-Structure Grammar
- contains a set of rules/productions
- derivation: expansion of rules
	- "a cat" can be derived from NP
- Parsing: generates a parse tree

## Backus Naur Form
- A notation for writing CFGs
- also used for programming languages

## Synchronous CFG
- Rules in two different languages, used for machine translation.

## CKY Parsing
- Bottom up dynamic programming
	- requires the grammar to be in Chomsky Normal Form
